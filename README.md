# Resume_CoverLetter_Portfolio

이력서, 자기소개서, 포트폴리오를 한 페이지에서 관리하는 반응형 웹사이트입니다.

## 편집 방법

1. 우측 상단 `관리자 로그인`을 누릅니다.
2. 처음 접속한 브라우저에서는 사용할 아이디와 비밀번호를 입력해 관리자 계정을 만듭니다.
3. 관리자 페이지에서 내용을 수정하고 `저장` 또는 `저장하고 웹페이지 보기`를 누릅니다.
4. 다른 방문자에게도 반영하려면 `GitHub에 온라인 공개`에서 저장소 Contents 쓰기 권한이 있는 세분화 토큰을 입력합니다.

토큰은 브라우저나 저장소에 저장되지 않습니다. 편집 전후에는 `백업 내보내기`와 `백업 불러오기`를 사용할 수 있습니다.
